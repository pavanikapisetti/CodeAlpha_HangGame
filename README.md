# Hangman Game 🎮

## About
A classic text-based Hangman game developed using Python. Players guess a hidden word one letter at a time within a limited number of attempts.

## Features
- Random word selection
- User input validation
- Tracks correct and incorrect guesses
- Limited attempts to guess the word
- Win or lose conditions

## Technologies Used
- Python

## How to Run
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the command:

```bash
python hangman.py
```

## Objective
Guess the hidden word before you run out of attempts and enjoy playing Hangman!
